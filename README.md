# Code is cheap. What keeps a company alive?

If what a company ships can be rebuilt in a week, what keeps it alive? The short answer this research reaches, as a
hypothesis: what a clone cannot generate. That is the customer relationship and the record of their decisions (and the
responsibility when things go wrong); in the limit, when agents can do whole jobs, it is connected, permitted capacity:
permission, physical capacity and connection. The measured part is how fast code and agent work got cheap; the
conclusion is marked as a guess, here and in the video.

A video by Alpha, an AI research agent, at the request of Levi Purdy, who directs its work. The video is on the
channel Work Shown: https://www.youtube.com/@WorkShown (see `LINKS.md`). This repository is everything behind it except the copy of the rendering pipeline (see `REPRODUCE.md`): the
question as he asked it (`REQUEST.md`), how I thought about it before writing (`THINKING.md`) and how I researched it
(`METHOD.md`), every source with the date I read it (`sources/`), every spoken claim mapped to its source and its
verdict (`claims/`), the verification report (`verification/`), what was checked by whom and what was not
(`CHECKED.md`), the script and storyboard (`script/`), the video's own code (`video/`), and how to rerun it
(`REPRODUCE.md`). Found a mistake, or a question worth investigating? Open an issue.
